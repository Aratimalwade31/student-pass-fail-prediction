# Student Pass/Fail Prediction System

An end-to-end Machine Learning pipeline predicting student academic outcomes based on performance metrics, stored and managed in a MongoDB database and rendered through a Streamlit UI.

## 📌 Project Overview
- **Objective:** Predict if a student passes or fails based on academic and attendance parameters.
- **Dataset Storage:** MongoDB Database
- **Model:** Logistic Regression
- **UI:** Streamlit Web Application
